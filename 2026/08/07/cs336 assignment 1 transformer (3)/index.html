Scaled Dot-Product Attention

终于到了注意力了，伟大的assignment 1行程已经走过了一大半。

我们现在将实现缩放点积注意力（scaled dot-product attention）。作为一个前置步骤，Attention操作的定义将使用softmax。

softmax是一种操作，它接收一个未归一化的向量，并将其转换为一个归一化的分布：

softmax(v)i=exp⁡(vi)∑j=1nexp⁡(vj)softmax(v)_i = \frac{\exp(v_i)}{\sum ^n_{j=1}\exp(v_j)} softmax(v)i​=∑j=1n​exp(vj​)exp(vi​)​

请注意，当viv_ivi​很大的时候，exp⁡(vi)\exp(v_i)exp(vi​)可能会变成 inf（此时 inf/inf = NaN）。

可以通过“softmax对于给所有输入加上同一个常数c是不变的”的性质，从而避免这个问题。

可以利用这一性质来提高数值稳定性——通常我们会从向量v的所有元素中减去它的最大值，使得新的最大值变为0。

Masking（掩码）：
有时对注意力操作的输出进行掩码是很方便的。一个掩码应具有形状M∈{True,False}n×mM \in \{ \text{True}, \text{False} \}^{n \times m}M∈{True,False}n×m，这个布尔矩阵的每一行 i 表示查询 i 应该关注哪些键。

按照惯例（并且有点容易混淆），在位置 (i, j) 上：

  • 值为 True 表示查询 i 会关注键 j；

  • 值为 False 表示查询 i 不会关注键 j。

换句话说，值为 True 的 (i, j) 对应的位置是“信息流动”的位置。

例如，考虑一个形状为1×31 \times 31×3的掩码矩阵[[True,True,False]][[ \text{True}, \text{True}, \text{False} ]][[True,True,False]]，则这个单一的查询向量只会关注前两个键。

从计算的角度来看，使用掩码比对子序列分别计算注意力要高效得多。

我们可以通过在 softmax 之前的得分矩阵(QTKdk)\left(\frac{Q^TK}{\sqrt{d_k}}\right)(dk​​QTK​)中，把掩码矩阵中为 False 的位置加上一个−∞-\infty−∞，来实现这一点。

Causal Multi-Head Self-Attention

因果多头自注意力（Causal Multi-Head Self-Attention）

我们将实现多头自注意力部分，多头自注意力能够从多方面对数据进行解读，效果比单一注意力更全面。从数学上讲，应用多头注意力的运算公式如下：

MultiHead(Q,K,V)=Concat(head1,…,headh)\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) MultiHead(Q,K,V)=Concat(head1​,…,headh​)

其中 headi=Attention(Qi,Ki,Vi)\text{head}_i = \text{Attention}(Q_i, K_i, V_i)headi​=Attention(Qi​,Ki​,Vi​)

这里 (Qi,Ki,Vi)(Q_i, K_i, V_i)(Qi​,Ki​,Vi​) 分别是 Q、K、V 的第 (i∈1,…,h)(i \in {1, \dots, h})(i∈1,…,h) 个切片，切片大小分别为 (dk)(d_k)(dk​) 或 (dv)(d_v)(dv​) 的嵌入维度。Attention就是上一小节的scaled dot-product attention操作。

由此，我们可以得到多头自注意力的运算公式：

MultiHeadSelfAttention(x)=WOMultiHead(WQx,WKx,WVx)\text{MultiHeadSelfAttention}(x) = W_O \text{MultiHead}(W_Q x, W_K x, W_V x) MultiHeadSelfAttention(x)=WO​MultiHead(WQ​x,WK​x,WV​x)

这里的可学习参数为：

WQ∈Rhdk×dmodel,WK∈Rhdk×dmodel,WV∈Rhdv×dmodel,WO∈Rdmodel×hdvW_Q \in \mathbb{R}^{h d_k \times d_\text{model}}, \quad W_K \in \mathbb{R}^{h d_k \times d_\text{model}}, \quad W_V \in \mathbb{R}^{h d_v \times d_\text{model}}, \quad W_O \in \mathbb{R}^{d_\text{model} \times h d_v} WQ​∈Rhdk​×dmodel​,WK​∈Rhdk​×dmodel​,WV​∈Rhdv​×dmodel​,WO​∈Rdmodel​×hdv​

由于在多头注意力操作中 Q、K、V 会被切片，我们可以认为 (WQ,WK,WV)(W_Q, W_K, W_V)(WQ​,WK​,WV​) 沿输出维度为每个 head 分开处理。当这一过程实现后，你应该通过三个矩阵乘法就能计算出 key、value 和 query 的投影。

进阶要求：可以尝试将 key、query、value 的投影合并到一个单一的权重矩阵中，这样就只需要一次矩阵乘法即可完成投影操作

因果掩码（Causal Masking）

在实践中，需要防止模型访问序列中的未来 token。换句话说，如果模型得到一个 token 序列 (t1,…,tn)(t_1, \dots, t_n)(t1​,…,tn​)，并希望计算前缀(t1,…,ti)(t_1, \dots, t_i)(t1​,…,ti​)（其中 (i < n)）的下一词预测时，模型不能访问位置 (ti+1,…,tn)(t_{i+1}, \dots, t_n)(ti+1​,…,tn​) 的 token 表示。原因是，在推理阶段生成文本时，这些未来token并不可见，同时访问它们会泄露真实下一词的信息，使语言建模预训练任务变得过于简单。

对于输入序列 (t1,…,tn)(t_1, \dots, t_n)(t1​,…,tn​)，一种直接方法是对每个前缀单独运行多头自注意力 n 次。但更高效的方法是使用因果注意力掩码（causal attention masking）：

  • 对于 token (i)，它只能 attend 到所有 (j≤i)(j \le i)(j≤i) 的位置。

  • 可以使用torch.triu或广播索引比较来构造这个掩码。

  • 你已经在缩放点积注意力实现中支持了attention mask，因此可以直接利用这一点。

RoPE（旋转位置编码）的应用

  • RoPE 应用于query和key向量，但不应用于 value 向量。

  • 在多头注意力中，每个 head 是独立应用注意力的，因此head维度应当作为批量维度处理。

  • 也就是说，对于每个 head，query 和 key 都要应用完全相同的 RoPE 旋转，以保证注意力计算的一致性。

Experiment: Transformer Block

在各个部分完成后，终于可以将它们组合起来了。一个Transformer block 主要分为两个部分：前半部分是因果多头自注意力机制（带RoPE），后半部分是逐位置前馈网络（我们已经实现了SwiGLU）。每个部分都需要先进行RMSNorm，再进行主要操作，最后加入残差连接。

具体来说，Transformer块的前半部分应该执行下面的一组更新，输入x然后输出y:

y=x+MultiHeadSelfAttention(RMSNorm(x))y=x+MultiHeadSelfAttention(RMSNorm(x)) y=x+MultiHeadSelfAttention(RMSNorm(x))
